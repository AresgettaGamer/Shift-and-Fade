# Shift & Fade examples

## Waystones

`waystones/` contains **Shift & Fade: Waystones v1.0.0**, a complete playable companion add-on and the official real-world reference implementation of the public Shift & Fade Protocol v2 SDK.

Unlike a minimal code snippet, this example is intentionally a full gameplay system: persistent destinations, natural/village generation, portable travel items, Teleport Pads and optional WATI Providers. It consumes the same public copy-in SDK available to third-party creators and does not import Shift & Fade internals.

The project may also be distributed independently (for example on CurseForge) because it is useful as normal gameplay content.
